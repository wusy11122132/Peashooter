# 今日心象局

「今日心象局」是一款神秘温柔的塔罗式心灵占卜网页小游戏。它使用真实塔罗体系中的大阿卡纳牌义，通过主题、心情、正逆位和追问组合出更有上下文的解读，帮助用户进行轻量的自我观察。

## 第一版目标

- 纯前端静态网页，打开即玩，兼容手机和桌面浏览器。
- 先实现 13 张连续的大阿卡纳牌，保留真实牌名与核心牌义。
- 支持五类主题、正逆位、追问、行动建议和本地历史记录。
- 结果避免绝对预言，不替代心理、医疗或现实决策建议。
- 为后续扩展至完整 78 张牌、三牌阵和 PWA 保留数据结构。

## 本地运行

无需构建工具，直接打开 `index.html` 即可体验。运行核心测试：

```bash
npm test
```

## 目录

- `index.html`：应用结构与页面文案
- `styles.css`：神秘温柔的桌面与移动端视觉
- `app.js`：牌库、随机抽牌、解读组合和交互逻辑
- `tests/core.test.mjs`：核心占卜逻辑测试
